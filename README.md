# SCA Alumni

The mobile app for the School of Communication Arts alumni community, published by Scaffold AI Ltd.

- One codebase for iPhone and Android, built with Expo (React Native).
- App identifier on both stores: `ai.scaffoldworks.scaalumni`.
- Screen designs: https://claude.ai/artifact/6EdsmqmTaHT2oPMaxVA1Cy

## Status

Foundation only: the standard Expo starter project, renamed and configured. No SCA screens are built yet.

## Run it locally

```
npm install
npx expo start
```
